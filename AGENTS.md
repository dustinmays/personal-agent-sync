# Agent guidance

This repository is a reviewed, public-facing-by-default exchange of portable learnings between separate Hermes environments.

- Read `README.md` and `docs/sharing-protocol.md` before adding or editing content.
- Never copy raw memory, user profiles, transcripts, logs, credentials, or confidential work/personal data here.
- Generalize and sanitize work-derived material; include evidence, scope, and limitations. Prefer a portable skill for a repeatable procedure and a learning note for a specific finding.
- Do not claim a finding is verified without evidence. Keep the original source/context non-identifying.
- Do not add automation that writes into either Hermes profile or synchronizes memory without explicit approval.
- Keep contributions small and reviewable. Do not push or change GitHub settings unless asked.
